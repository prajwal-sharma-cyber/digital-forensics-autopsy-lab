# Digital Forensics — Autopsy Lab

A beginner digital-forensics portfolio project documenting a safe, fictional forensic investigation workflow using Autopsy concepts.

> Do not upload real personal devices, private files or sensitive evidence to this repository.

## Investigation Workflow
```text
Evidence Acquisition → Integrity → Examination → Artefact Review
→ Timeline Analysis → Findings → Report
```

## Evidence Categories
File-system metadata, browser artefacts, user activity, deleted-file indicators, timestamps and hashes.

## Evidence Handling
Maintain an evidence identifier, acquisition date, hash, analyst, examination notes and findings.

## Skills
Digital forensics, evidence handling, timeline analysis and technical reporting.
