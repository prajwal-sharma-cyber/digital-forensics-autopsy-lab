# Fictional Forensic Case Notes

## Case
A fictional company laptop is suspected of policy-violating activity.

## Questions
1. What user activity occurred?
2. Which files were accessed?
3. Which timestamps are relevant?
4. Are there indicators of unauthorised activity?
5. What evidence supports each finding?

## Analyst Principle
Separate observations from conclusions.

Observation: a file was created at a particular time.

Conclusion: additional evidence is required before determining who created it or why.
